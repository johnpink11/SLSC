\begin{abstract}
Multi-turn mathematical reasoning with small language models (SLMs, $\sim$1B--10B parameters) suffers from substantial performance degradation as conversation history accumulates, with recent work documenting up to 39\% accuracy drops. We propose \textit{Sparse Logic State Compression} (SLSC), a twin-agent framework that maintains reasoning state as atomic mathematical propositions rather than unstructured text. A reasoning agent generates chains of thought while a curator agent distills accumulated context into structured, addressable propositions. We evaluate SLSC on Math-100-multi, a 100-problem benchmark where each problem decomposes into 2--5 dependent sub-questions. Across four Qwen3.5 scales (0.8B--9B), SLSC achieves up to 85\% fully correct rate versus 62\% for uncompressed baselines, reducing per-turn input tokens by 62\%. However, natural-language summary shows comparable gains, suggesting benefits arise primarily from bounded context size rather than structured representation. A cautionary finding: augmenting propositions with Lean~4 formal type stubs consistently degrades accuracy due to stateless autoformalization without verifier feedback. Our work establishes structured state compression as an effective, training-free strategy, revealing that the core mechanism is preventing attention dilution rather than providing typed mathematical structure.
\end{abstract}
